# Changelog

## 2026-11-11 13:56 — feat(api): switch joke generation from OpenAI to Mistral

Jokes are now generated by Mistral (`mistral-small-latest`, 50-token cap) through the official `@mistralai/mistralai` SDK, replacing OpenAI's `gpt-3.5-turbo`. Mistral returns the same `choices[0].message.content` shape, so the frontend is unchanged. The app now reads `MISTRAL_API_KEY` instead of `OPENAI_KEY`, so the new key has to be set locally and on the host before deploying. The README and footer credit now name Mistral.
